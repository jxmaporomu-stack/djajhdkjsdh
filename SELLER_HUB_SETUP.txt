SELLER HUB SETUP - QUICK START

1) Upload/extract this complete project to Dischost, replacing the old project files with this integrated copy.
2) Keep your existing .env / config.json / data.db values. Do not overwrite your real .env with .env.example.
3) In Discord Developer Portal > Bot > Privileged Gateway Intents, enable Server Members Intent.
4) Ensure bot invite/role has Manage Channels and Manage Roles, plus View Channels, Send Messages, Embed Links, Read Message History.
5) Restart the bot and run /setup in the target server as Server Owner or a member with Manage Server.
6) Assign Global Owner, Co-Owner, and regional Director roles manually to the correct people.

Only /setup bypasses the vending license check. Existing vending/slot/ticket behavior remains licensed as before.
The bot role should be high enough in the role list to manage roles it creates. Leadership roles are intentionally not granted Administrator.
