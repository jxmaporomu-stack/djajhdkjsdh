SELLER HUB SETUP - FIXED COMMAND REGISTRATION

This build registers /setup as a server-specific (guild) slash command on every
server the bot is already in, and whenever it joins a new server. This avoids
waiting for Discord's global slash-command propagation.

1) Upload/extract this complete project to Dischost, replacing the old project files.
2) Keep your existing .env / config.json / data.db values. Do not overwrite your real .env.
3) Bot permissions required: Manage Channels, Manage Roles, View Channels,
   Send Messages, Embed Links, Read Message History.
4) For join/leave notices, enable Server Members Intent in Developer Portal.
5) Restart the bot. Wait for the console line showing [SELLER HUB] /setup registration.
6) In the target server, run /setup as the server owner or a member with Manage Server.

Only /setup bypasses the vending license check. Existing vending, ticket, and slot
commands keep their original license behavior. The bot's role must be above the
roles it creates/manages. Assign Global Owner, Co-Owner, and regional Director
roles manually after setup. Leadership roles do not receive Administrator.
